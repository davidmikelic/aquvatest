AQUVA — GitHub Pages package (AQUVA_GITHUB_READY.zip)
=====================================================

Target: GitHub Pages with custom domain www.aquva-test.com
This package is STATIC ONLY. It contains no PHP.

Deploy
1. Create/use the GitHub repository connected to aquva-test.com.
2. Extract this ZIP into the publishing branch/folder (usually the repo root or /docs).
3. Confirm CNAME contains: www.aquva-test.com
4. Confirm .nojekyll is present (required so GitHub serves css/js folders).
5. Enable GitHub Pages for that branch.
6. Keep Cloudflare Access (team login) if you already use it.

Indexing
- robots.txt Disallow: /
- Every page ships with a static <meta name="robots" content="noindex, nofollow">
  (and the pages also force noindex at runtime whenever the host is not www.aquva.hr)
- Canonical / hreflang / Open Graph URLs still point to https://www.aquva.hr (intentional)

Does NOT work on GitHub Pages
- Newsletter sign-up storage (js/newsletter-config.js endpoint is empty: forms show
  "not open yet"; the address is never sent anywhere and nothing is saved)
- api/geo.php country hint (browser language fallback is used)
- .htaccess rules (ignored by GitHub Pages)

Does work
- Full marketing site + shop UI (HR/EN/IT/DE)
- Cart UI, cookie settings, contact mailto, animations, assets
